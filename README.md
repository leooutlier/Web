# Sitio web · Leo Arévalo

Sitio estático (HTML, CSS y JavaScript) de Leo Arévalo, ingeniería del bienestar.

## Páginas

| Archivo | Página |
| --- | --- |
| `index.html` | Inicio |
| `sobre-mi.html` | Sobre mí |
| `servicios.html` | Servicios |
| `terminos.html` | Términos y condiciones |
| `privacidad.html` | Aviso de privacidad |
| `404.html` | Página no encontrada |

- `support.js`: animaciones, menú, acordeones y formularios. Debe ir junto a las páginas.
- `assets/`: imágenes y logos.

## Publicación

No necesita compilación. En Replit se publica como **Static**:

- Directorio público: `/`
- Build command: vacío
